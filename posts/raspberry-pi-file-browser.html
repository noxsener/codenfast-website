Raspberry Pi'de File Browser Kurulumu ve Kullanımı

Bu yazı, PiMyLifeUp - Installing and Using File Browser on the Raspberry Pi kaynağından Türkçe'ye çevrilerek hazırlanmıştır.

Bu proje, Raspberry Pi'nize File Browser'ı nasıl kuracağınızı gösterecek.

File Browser, tamamen web tarayıcınızdan kullanabileceğiniz, inanılmaz derecede kullanımı kolay bir dosya yöneticisidir. Bu web arayüzü, dosya sisteminizden dosya ve klasörleri yüklemenizi, indirmenizi ve silmenizi sağlar.

Özel bir yazılıma ihtiyaç duymadan dosyaları uzaktan yönetmek istiyorsanız, bu yazılım Raspberry Pi'nizde çalıştırmak için harika olabilir.

Hepsinden iyisi, File Browser kurulumu kolaydır ve bir Raspberry Pi'de çalışması için minimal yapılandırma gerektirir.

Bu web tabanlı dosya yöneticisini kullanmayı daha da basitleştirmek için, onu Docker kullanarak kuracak ve çalıştıracağız. Yazılım tek bir çalıştırılabilir dosya olsa da, Docker onu izole ve çalışır tutmayı kolaylaştırır.

Bu rehberin sonunda, istediğiniz dosya ve klasörlere doğrudan bir web tarayıcısından erişebileceksiniz.

Raspberry Pi'ye File Browser Web Arayüzü Kurulumu

Aşağıdaki bölümlerde, Raspberry Pi'nizde File Browser'ı kurma sürecinde size rehberlik edeceğiz.

Raspberry Pi'nizi Hazırlama

1. Raspberry Pi'mizde File Browser yazılımını kurup çalıştırmadan önce, işletim sisteminin güncel olduğundan emin olmalıyız.

Aşağıdaki iki komutu kullanarak paket listesi önbelleğini güncelleyin ve güncel olmayan tüm paketleri yükseltin.

sudo apt update
sudo apt upgrade -y

2. Raspberry Pi'niz güncellendikten sonra, Docker kurmaya geçebilirsiniz. File Browser'ı kurmak için Docker çalışma zamanına ihtiyacınız olacak.

Neyse ki, Raspberry Pi'nize Docker'ı nasıl kuracağınızı gösteren bir rehberimiz var. Bu rehberi takip edin, ardından bu eğitime geri dönün.

3. Docker kurulduktan sonra, bir sonraki adımımız File Browser'ın Docker Compose dosyasını, veritabanını ve yapılandırma dosyasını saklamak için bir dizin oluşturmaktır.

Terminalde aşağıdaki komutu kullanarak bu dizini oluşturabilirsiniz.

sudo mkdir -p /opt/stacks/filebrowser

4. Dizin oluşturulduktan sonra, cd komutunu kullanarak içine geçmemiz gerekiyor.

cd /opt/stacks/filebrowser

File Browser İçin Gerekli Dosyaları Ayarlama

5. File Browser'ın Raspberry Pi'de çalışması için, iki ek dizin oluşturmamız gerekiyor.

  • Birincisi, veritabanı dosyasını saklayacağımız "data" klasörüdür.
  • İkincisi, yapılandırma dosyasını saklamak için kullandığımız "config" dizinidir.

Bu iki dizini de oluşturmak için mkdir komutunu kullanabilirsiniz.

sudo mkdir data config

6. File Browser Docker konteyneri, Raspberry Pi'mizde içine yazabileceği boş bir "database" dosyası olmasını bekler.

Konteynerin kendisi bu dosyayı oluşturmayı denemez. Bu boş dosyayı touch komutunu kullanarak oluşturabiliriz.

sudo touch ./data/database.db

7. Veritabanı dosyasına ek olarak, çok basit bir yapılandırma dosyası da yazmamız gerekiyor.

Bu yapılandırma dosyasını yazmaya aşağıdaki komutu kullanarak başlayabilirsiniz.

sudo nano ./config/filebrowser.json

8. Bu dosyanın içine, aşağıdaki satırları girmek isteyeceksiniz. Bu dosyada ayarlamak isteyebileceğiniz tek seçenekler "baseURL" ve "address"tir.

{
  "port": 80,
  "baseURL": "",
  "address": "",
  "log": "stdout",
  "database": "/database.db",
  "root": "/srv"
}

9. Yapılandırma dosyasını doldurduktan sonra, CTRL + X, Y ve ardından ENTER tuşuna basarak kaydedip çıkabilirsiniz.

10. File Browser'ın çalışma şekli nedeniyle, bu yeni dosyaların ve dizinlerin kullanıcınıza ait olduğundan emin olmalısınız.

Bu dosya ve dizinlerin sahipliğini chown komutunu kullanarak alabilirsiniz.

"$USER" ortam değişkenini kullanarak, mevcut kullanıcınızın adını otomatik olarak ekliyoruz. Bunu farklı bir kullanıcı altında çalıştırmak isterseniz, bu kısmı onların kullanıcı adıyla değiştirin.

sudo chown -R $USER:$USER ./config ./data

Raspberry Pi'de File Browser'ı Yönetmek İçin Bir Docker Compose Dosyası Yazma

11. Artık Raspberry Pi'nizde File Browser için Compose dosyasını yazabileceğimiz noktadayız.

Bir Compose dosyası, konteynerinizi kurup çalıştırırken Docker'ın takip edeceği bir talimatlar kümesidir.

sudo nano compose.yaml

Docker Compose dosyalarınızı daha etkili bir şekilde yönetmek istiyorsanız, Pi'nize Dockge kurmanızı şiddetle tavsiye ederiz.

12. Bu Compose dosyasının içine, aşağıdaki satırları girmek isteyeceksiniz.

Bu dosyayı doldururken, üç yer tutucuyu değiştirmek isteyeceksiniz.

  • <USERID>: Bunu, File Browser'ın altında çalışmasını istediğiniz kullanıcının ID'siyle değiştirin. Bu yazılım aracılığıyla paylaştığınız dosyalar bu kullanıcı tarafından erişilebilir olmalıdır. Örneğin, Raspberry Pi OS'deki varsayılan kullanıcı için, "1000" ID'sini kullanırsınız.

  • <GROUPID>: Bu değeri, servisin hangi grup altında çalışması gerektiğini belirtmek için kullanın. Genellikle, bir kullanıcının aynı ID'yi kullanan bir grubu vardır, bu yüzden kullanıcınız için kullandığınız aynı değeri kullanabilirsiniz. Örneğin, Raspberry Pi OS'de varsayılan kullanıcınızı kullanıyorsanız, bunu "1000" ile değiştirebilirsiniz.

  • <DIRECTORY>: Değiştirmeniz gereken son değer, File Browser web arayüzü üzerinden hangi dizinlerin kullanılabilir olması gerektiğini belirtmenizi sağlar. Örneğin, tüm sisteminize erişim vermek isterseniz, tek bir eğik çizgi "/" kullanabilirsiniz. Ancak, bunu gerçekten önermeyiz. Bunun yerine, bunu belirli bir dizinle değiştirmek en iyisi olacaktır. Örneğin, "pi" adlı bir kullanıcının ana dizinini paylaşmak için, "/home/pi/" değerini kullanırdık.

    services:
    filebrowser:
    image: filebrowser/filebrowser
    user: ":"
    ports:
    - 8080:80
    volumes:
    - :/srv
    - /opt/stacks/filebrowser/data/database.db:/database.db
    - /opt/stacks/filebrowser/config/filebrowser.json:/.filebrowser.json
    restart: always

13. Docker Compose dosyasını doldurmayı bitirdikten sonra, CTRL + X, Y ve ardından ENTER tuşuna basarak kaydedip çıkın.

File Browser Konteynerini Başlatma

14. Compose dosyası artık yazıldığına göre, Raspberry Pi'nizde File Browser yazılımını başlatmak aşağıdaki komutu kullanmak kadar kolaydır.

Web arayüzüne erişmek için kullanacağınız şifre, ilk kurulum sürecinde görüntülenir, bu yüzden lütfen dikkat edin.

docker compose up

15. Şimdi, başlatma sırasında, aşağıdakine biraz benzeyen bir satır görmelisiniz. Burada belirtilen şifreyi not edin, çünkü Filebrowser'a erişmek için kullanacağınız şey budur.

Bu şifreyi bir daha göremeyeceksiniz.

filebrowser-1  | 2025/07/28 04:16:45 User 'admin' initialized with randomly generated password: ElDotpWrfVqE3krD

16. Şifreyi not ettikten sonra, CTRL + C tuşuna basarak konteyneri durdurun.

17. Son olarak, aşağıdaki komutu kullanarak Raspberry Pi'nizde File Browser'ı tekrar başlatın.

Bu sefer "-d" seçeneğini kullandığımızı fark edeceksiniz. Bu seçenek, yazılımı başlattıktan sonra Docker'ın terminalden ayrılmasını (detach) sağlar.

docker compose up -d

File Browser Web Arayüzüne Erişim

18. File Browser artık Raspberry Pi'nizde çalışır durumda olduğuna göre, muhtemelen web arayüzüne nasıl erişeceğinizi bilmek isteyeceksiniz.

Öncelikle, Raspberry Pi'nizin IP adresine ihtiyacınız olacak. IP'yi bilmiyorsanız, aşağıda gösterildiği gibi her zaman hostname komutunu kullanabilirsiniz.

hostname -I

19. Favori web tarayıcınızda aşağıdaki adrese gidin.

"<IPADRESI>" kısmını Pi'nizin IP'siyle değiştirdiğinizden emin olun.

http://<IPADRESI>:8080

20. File Browser'a eriştiğinizde, sizi aşağıdaki giriş ekranı karşılayacaktır.

Varsayılan kullanıcı adı ve şifreyle giriş yapmanız gerekecek. Kullanıcı adı için "admin" yazın ve ardından File Browser'ın başlatılması sırasında oluşturulan şifreyi kullanın.

Varsayılan bilgileri doldurduktan sonra, "Login" düğmesine tıklayın (2.).

21. File Browser'a giriş yaptıktan sonra, Raspberry Pi'nizdeki dosya ve klasörlere tam erişiminiz olacak.

Bu arayüzü, sisteminizde dosya indirmek ve yeni dosyalar oluşturmak için kullanabilirsiniz.

Varsayılan Şifreyi Değiştirme

22. File Browser'ı kutudan çıktığı gibi kullanmanın büyük bir riski, admin kullanıcısının kullanıcı adının ve şifresinin inanılmaz derecede basit olmasıdır. Neyse ki, bu şifreyi güncellemek oldukça basit bir süreçtir.

Ekranın sol tarafındaki kenar çubuğunu kullanarak "Settings" menüsüne geçin.

23. "Change Password" başlığı altında, admin kullanıcısı için yeni ve güvenli bir şifre girin (1.).

Yeni şifreyi doldurduktan sonra, yeni şifreyi onaylamak için "Update" düğmesine tıklayın (2.).

File Browser'ın En Son Sürümüne Güncelleme

Raspberry Pi'nizde File Browser'ı çalıştırmak için Docker kullanmanın bir avantajı, güncellemenin kolay olmasıdır.

Bu bölüm, File Browser'ın en son sürümüne güncellemek için hızlı adımları gösterecek.

1. Terminalde, Docker Compose dosyasını yazdığınız dizine geçmek için aşağıdaki komutu kullanmak isteyeceksiniz.

File Browser'ı güncellemek için bu dizinde olmanız gerekecek.

cd /opt/stacks/filebrowser

2. Şimdi aşağıdaki komutu çalıştırarak File Browser imajının en son sürümünü çekmek için Docker kullanabiliriz.

docker compose pull

3. Yeni bir sürüm indirildikten sonra, şu anda çalışan konteyneri buna güncellemek için aşağıdaki komutu kullanabiliriz.

Docker yeni sürümü algılayacak, çalışan konteyneri durduracak ve ardından yeni sürümü kullanarak başlatacaktır.

docker compose up -d

Sonuç

Umarız Raspberry Pi'nizde File Browser konteynerini başarıyla çalışır hale getirmişsinizdir.

Bu yazılım oldukça kullanışlıdır ve kullanımı kolay bir web arayüzü üzerinden sisteminizdeki dosyaları yönetmenizi sağlar. Kullanışlılığını daha da artırmak için, Tailscale gibi bir yazılıma göz atmak isteyebilirsiniz.

Bu dosya tarayıcısını çalıştırmak için yardıma ihtiyacınız olursa, aşağıya yorum bırakmaktan çekinmeyin.
