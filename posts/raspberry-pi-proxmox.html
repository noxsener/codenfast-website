Raspberry Pi'ye Proxmox Nasıl Kurulur

Bu yazı, PiMyLifeUp - How to Install Proxmox on the Raspberry Pi kaynağından Türkçe'ye çevrilerek hazırlanmıştır.

Bu eğitimde, Raspberry Pi'ye Proxmox Sanal Ortamını nasıl kuracağınızı öğreneceksiniz.

Proxmox Virtual Environment, inanılmaz derecede güçlü ve kullanışlı bir web arayüzüne sahip açık kaynaklı bir sanallaştırma platformudur.

Yerleşik web arayüzünü kullanarak Raspberry Pi'nizde sanal makineleri ve konteynerleri kolayca yönetebilirsiniz.

Bu web arayüzü, yazılım tanımlı depolama, ağ ve daha fazlasını kurmanızı bile sağlar. Raspberry Pi'nizde sanal makineler çalıştırmak istiyorsanız, Proxmox başvurulacak çözümlerden biridir.

Proxmox VE'deki son gelişmeler sayesinde, artık ARM sistemlerini destekliyor. Dezavantajı, ekibin ARM64 için herhangi bir derleme sağlamamasıdır. Neyse ki, Pi'miz gibi ARM sistemleri için destek ekleyen üçüncü taraf bir Proxmox çatalını (fork) kullanabiliriz.

Dayandığımız çatal Pxvirt adını taşıyor. Bu çatal, Proxmox VE ile özellik paritesini korurken, Proxmox'un ARM üzerinde daha da iyi çalışmasına yardımcı olan birçok ek optimizasyon içeriyor.

Bu rehberde kuracağınız Proxmox Sanal Ortamının sürümü, çalıştırdığınız Raspberry Pi OS sürümüne bağlıdır. Bookworm çalıştırıyorsanız, Proxmox 8'i alacaksınız. Raspberry Pi OS Trixie çalıştırıyorsanız, Proxmox 9'u çalıştırıyor olacaksınız.

Raspberry Pi'nizde sanal makineler çalıştırırken, çok ağır bir şey kullanmaktan kaçının. Raspberry Pi'ler en güçlü makineler değildir, ancak birkaç küçük VM'yi idare edebilmeleri gerekir. Raspberry Pi 5 gibi daha yeni Pi'leri Proxmox ile kullanarak daha iyi bir deneyim yaşarsınız.

Bu eğitimin çalışması için, Raspberry Pi OS Lite Bookworm veya Trixie'nin 64-bit sürümünü çalıştırıyor olmanız gerektiğini lütfen unutmayın. Başka işletim sistemleri kullanmanın çalışacağı garanti edilmez ve muhtemelen sorunlara neden olur.

Raspberry Pi'ye Proxmox Kurulumu

Aşağıdaki bölümlerde, Raspberry Pi'nize Proxmox sanal ortamını kurma sürecinde size rehberlik edeceğiz.

Bu adımları Raspberry Pi OS Lite'ın temiz bir kurulumunu kullanarak takip etmenizi şiddetle tavsiye ederiz. Özellikle, 64-bit sürümü kullanıyor olmalısınız.

İşletim sisteminin temiz olmayan bir sürümü, Proxmox kurulum sürecinin bozulmasına neden olabilir.

Proxmox İçin Raspberry Pi'nizi Hazırlama

1. Raspberry Pi'ye Proxmox kurmadan önceki ilk görevimiz, paket listesi önbelleğini güncellemek ve güncel olmayan tüm paketleri yükseltmektir.

Terminalde aşağıdaki iki komutu kullanarak her iki görevi de gerçekleştirebilirsiniz.

sudo apt update
sudo apt upgrade

2. Bir sonraki adımınız, curl'un Pi'nizde kurulu olduğundan emin olmaktır. Proxmox'u kurmak için dayanacağımız PXVirt deposunun GPG anahtarını almak için curl kullanacağız.

Bu paketi terminalde aşağıdaki komutu kullanarak kurabilirsiniz.

sudo apt install curl

3. Bu eğitime devam etmeden önce, Raspberry Pi'nizi statik bir IP adresi kullanacak şekilde ayarlamalısınız.

Bunu yapmanın en iyi yolu, yönlendiricinizde DHCP rezervasyonu kullanmaktır. Ancak, yönlendiricinize erişiminiz yoksa, bunu Raspberry Pi'niz üzerinden nasıl yapacağınızı gösteren bir rehberimiz var.

Proxmox İçin Hosts Dosyanızı Değiştirme

4. Statik bir IP adresi ayarladıktan sonra, artık hosts dosyasını düzenlememiz gerekiyor. Proxmox, ana bilgisayar adınızın (hostname) Raspberry Pi'nizin IP adresine işaret etmesini bekler.

Aşağıdaki komutu çalıştırarak Raspberry Pi'de nano metin editörünü kullanarak hosts dosyasını düzenlemeye başlayabilirsiniz.

sudo nano /etc/hosts

5. Hosts dosyası açıkken, aşağıdakine benzer bir satır görmelisiniz. Bizim ana bilgisayar adımız varsayılan "raspberrypi" olarak ayarlı, ama sizinki farklı olabilir.

127.0.0.1            raspberrypi

Bu satırı bulduktan sonra, "127.0.0.1" kısmını Raspberry Pi'nizin yerel IP adresiyle değiştirmek isteyeceksiniz.

Bizim durumumuzda, Pi'mizin IP'si "192.168.0.32" olduğundan, satırı aşağıdaki gibi görünecek şekilde değiştirdik.

192.168.0.32            raspberrypi

6. Bu değişiklikleri yaptıktan sonra, CTRL + X, Y ve ardından ENTER tuşuna basarak kaydedip çıkın.

7. Değişikliklerimizin çalıştığını doğrulamak için, Raspberry Pi'mizin IP adresini yazdırmak amacıyla hostname komutunu kullanabiliriz.

hostname --ip-address

Her şeyi doğru yapılandırdıysanız, Pi'nizin statik IP'si döndürülmelidir.

192.168.0.32

Cloud Init'in Hosts Dosyasını Yönetmesini Durdurma

8. Raspberry Pi OS'nin yeni sürümlerinde artık Cloud-init kurulu geliyor. Bu kurulumun bir parçası olarak, artık hosts dosyasını otomatik olarak güncelleyecek ve değişikliklerimizi kaldıracaktır.

Neyse ki, "cloud.cfg" dosyasını değiştirip belirli bir seçeneği devre dışı bırakarak bu işlevselliği kapatabiliriz.

sudo nano /etc/cloud/cloud.cfg

9. Bu dosyanın içinde, aşağıdaki satırı bulmak isteyeceksiniz. Bu, "cloud_init_modules" başlığı altında olacaktır.

  - update_etc_hosts

Bu satırı bulduktan sonra, yapmanız gereken tek şey önüne bir kare işareti (#) eklemektir. Bu, o satırı yorum satırı yapar ve yeniden başlattığınızda Cloud-Init'in değişikliklerimizi geçersiz kılmayacağı anlamına gelir.

#  - update_etc_hosts

10. Bu değişikliği yaptıktan sonra, CTRL + X, Y ve ardından ENTER tuşuna basarak kaydedip çıkın.

root Kullanıcısı İçin Bir Şifre Belirleme

11. Raspberry Pi'mizde Proxmox kullanmak için yapmamız gereken bir sonraki şey, "root" kullanıcısı için bir şifre belirlemektir. Bu kullanıcı için bir şifre belirlemezsek, Proxmox web arayüzü üzerinden giriş yapamayız.

Terminalde aşağıdaki komutu kullanarak root kullanıcısı için bir şifre belirleyebilirsiniz.

sudo passwd root

12. Bir şifre belirlemek için, aşağıda gösterildiği gibi iki kez girmeniz gerekir. Bunun için güçlü bir şifre belirlemenizi öneririz.

Bir şifre yöneticisi, güçlü şifreler oluşturmayı ve saklamayı önemli ölçüde kolaylaştırır.

New password:
Retype new password:

Raspberry Pi'nize Proxmox Port Deposunu Ekleme

13. Sonunda PXVirt deposunu Raspberry Pi'mize ekleyebileceğimiz aşamaya geldik. Bu depo üçüncü bir taraf tarafından yönetilir ancak Raspberry Pi'nin donanımında çalışabilecek Proxmox sürümlerini kurmamızı sağlar.

Bu süreçteki ilk adımımız, depo için GPG anahtarını eklemektir. Bu anahtar, paketlerin gerçekten PXVirt deposundan geldiğini doğrulamaya yardımcı olur.

curl -L https://mirrors.lierfang.com/pxcloud/lierfang.gpg | sudo tee /usr/share/keyrings/lierfang.gpg >/dev/null

14. Proxmox'u kurup çalıştırmamızı sağlayan asıl depoyu eklemeden önce, "/etc/os-release" dosyasını okumak için "source" komutunu kullanmalıyız. Bu, mevcut işletim sistemi kod adını kolayca almamızı ve yazdırmamızı sağlayacaktır.

Bu dosyayı aşağıdaki komutu çalıştırarak okuyabilirsiniz.

source /etc/os-release

15. GPG anahtarı eklendikten sonra, artık deponun kendisini kaynak listemize ekleyebiliriz.

Depo bağlantısını "pveport.list" adlı bir dosyaya kaydetmek için aşağıdaki komutu kullanın.

echo "deb [arch=arm64 signed-by=/usr/share/keyrings/lierfang.gpg] https://mirrors.lierfang.com/pxcloud/pxvirt $VERSION_CODENAME main" | sudo tee  /etc/apt/sources.list.d/pveport.list

16. Kaynak listesinde değişiklik yaptığımızdan, aşağıdaki komutu çalıştırarak paket listesi önbelleğini tekrar güncellememiz gerekiyor.

Bunu yapmazsak, paket yöneticisi az önce eklediğimiz depodan haberdar olmayacaktır.

sudo apt update

Proxmox İçin Pi'nizin Ağını Hazırlama

Sonraki birkaç bölüm, Proxmox kurulduktan sonra ağınızın çalışmaya devam etmesini sağlayacak. Bu adımlar olmadan, daha sonra ağ bağlantısını kaybedersiniz.

Network Manager'ın Ağınızı Yönetmesini Önleme

17. Varsayılan olarak, Raspberry Pi OS, açılışta başlayacak şekilde kurulmuş ve ayarlanmış Network Manager ile birlikte gelir. Proxmox'un kendi ağ yapılandırmasını otomatik olarak yönetip bozmasını önlemek için bu servisi devre dışı bırakmamız gerekiyor.

Bu süreçteki ilk adım, Raspberry Pi'niz açıldığında otomatik olarak başlamaması için "networkmanager" servisini devre dışı bırakmaktır.

sudo systemctl disable NetworkManager

18. Ardından, terminalde aşağıdaki komutu kullanarak NetworkManager'ın çalışmasını durdurabiliriz.

Bu, servisi hemen durduracak ve Raspberry Pi'nizi yeniden başlatma zahmetinden sizi kurtaracaktır.

sudo systemctl stop NetworkManager

19. Son olarak, güvenlik önlemi olarak, NetworkManager servisine bir maske de uygulayacağız. Bir maske uygulamak, önce maske kaldırılmadan bu servisin yeniden etkinleştirilmesini önler.

sudo systemctl mask NetworkManager

ifupdown2 ve Resolvconf Kurulumu

20. Her şey hazır olduğuna göre, sonunda Raspberry Pi'ye Proxmox kurmaya başlayabiliriz.

Sistemimize kurulması gereken ilk iki paket "ifupdown2"dir. Proxmox, ağı yönetmek için "ifupdown2" paketini kullanır.

sudo apt install ifupdown2

"ifupdown2" kurarken aşağıdaki hata mesajını görürseniz, aşağıdaki "a" ve "b" adımlarını takip etmeniz gerekecek. Aksi takdirde, doğrudan 21. adıma geçin.

error: Another instance of this program is already running.

a. "already running" hatasını aşmak için, ifupdown2'yi çalışır hale getirmek amacıyla bazı geçici çözüm adımları uygulamamız gerekecek.

Bu adım, ifupdown2 paketinin kurulum sırasında aradığı geçici bir dosyayı silmeyi içerir.

sudo rm /tmp/.ifupdown2-first-install

b. Geçici dosya kaldırıldıktan sonra, aşağıdaki komutu kullanarak ifupdown2 için kurulum sürecini tekrar çalıştırmamız gerekiyor.

Bu, son kurulum adımlarının doğru şekilde yürütülmesini sağlayacaktır.

sudo apt install ifupdown2

Ağ Arayüzlerinizi Değiştirme

21. Bir sonraki adımımız, interfaces dosyasında bazı düzenlemeler yapmaktır. Bu değişiklikleri yapmazsak, Raspberry Pi'niz yeniden başladığında Proxmox bozulacaktır.

Bu değişikliklerle, "eth0" arayüzümüzü manuel olarak ayarlayacak ve bağlantılarınızı köprüleyecek (bridge) ve sanal makineleriniz tarafından kullanılacak yeni bir ağ arayüzü oluşturacağız.

Bu dosyayı yazmaya aşağıdaki komutu kullanarak başlayabilirsiniz.

sudo nano /etc/network/interfaces

22. Bu dosyanın içine, dosyanın altına aşağıdaki satırları eklemek isteyeceksiniz. Bu arayüzlerin bazılarının otomatik olarak belirtilmiş olma ihtimali var, onları silin ve burada belirttiğimiz değerlerle değiştirin.

Bu dosyayı doldururken iki değeri değiştirmeniz gerekiyor.

  • <IPADDRESS>: Bu yer tutucuyu Raspberry Pi'nizin IP adresiyle değiştirin. Bu, erişilebilir olduğu yerel IP olmalıdır.

  • <GATEWAY>: Bu yer tutucuyu ağ geçidinizin IP adresiyle değiştirin. Genellikle bu, yönlendiricinizin IP'si olacaktır. Çoğu durumda bu aslında "192.168.0.1" olacaktır.

  • <DNSSERVER>: Bu yer tutucuyu tercih ettiğiniz bir DNS çözücünün IP adresiyle değiştirin. Örneğin, Cloudflare'in DNS hizmetini kullanmak isterseniz, bu yer tutucuyu "1.1.1.1 1.0.0.1" ile değiştirirsiniz. Bir diğer popüler seçenek Google'ınkidir, bu durumda "8.8.8.8 8.8.4.4" kullanırsınız.

    auto lo
    iface lo inet loopback

    auto eth0
    iface eth0 inet manual

    auto vmbr0
    iface vmbr0 inet manual
    address
    gateway
    dns-nameservers
    netmask 255.255.255.0
    bridge-ports eth0
    bridge-stp off
    bridge-fd 0

Aşağıda, bu dosyayı doldurmayı bitirdikten sonra nasıl görünebileceğine dair bir örnek bulunmaktadır.

auto lo
  iface lo inet loopback

auto eth0
  iface eth0 inet manual

auto vmbr0
iface vmbr0 inet manual
        address 192.168.0.200
        gateway 192.168.0.1
        dns-nameservers 1.1.1.1 1.0.0.1
        netmask 255.255.255.0
        bridge-ports eth0
        bridge-stp off
        bridge-fd 0

23. Bu dosyayı doldurduktan sonra, CTRL + X, Y ve ardından ENTER tuşuna basarak kaydedip çıkın.

24. Bu ağ değişikliklerinin çalıştığından emin olmak için, terminalde aşağıdaki komutu çalıştırarak Raspberry Pi'nizi yeniden başlatın.

sudo reboot

Raspberry Pi'ye Depodan Proxmox Kurulumu

25. Son olarak, terminalde aşağıdaki komutu yazarak Proxmox VE'yi ve birkaç gerekli paketi kurabilirsiniz.

Bu kurulum süreci birkaç dakika sürebilir, bu yüzden birkaç dakika beklemeye hazır olun. Ayrıca, kurulum sırasında geçmeniz gereken birkaç istem olacaktır.

sudo apt install proxmox-ve postfix open-iscsi pve-edk2-firmware-aarch64

26. Kurulum sırasında, Postfix'i yapılandırmanız istenecektir. Bu menüde hareket etmek için ARROW (ok) tuşlarını, seçmek için ENTER tuşunu kullanabilirsiniz.

Burada ne yaptığınızdan emin değilseniz, "Local only" seçeneğini seçin.

27. Ardından, Postfix'in kullanacağı posta adını ayarlamanız istenecektir (1.).

Yine, burada ne yaptığınızdan emin değilseniz, varsayılan adı bırakın ve devam etmek için ENTER tuşuna basın (2.).

28. Kurulumdan sonra aşağıdakine benzer bir hata mesajıyla karşılaşırsanız, kurulum komutunu tekrar çalıştırmayı deneyin.

Errors were encountered while processing:
 pxvirt-spdk

Proxmox Web Arayüzüne Erişim

29. Proxmox Raspberry Pi'nize kurulumunu tamamladığında, web arayüzüne erişmek güvenli olmalıdır.

Web arayüzüne erişmek için ihtiyacınız olan tek şey Raspberry Pi'nizin IP adresidir.

hostname -I

30. IP adresiniz elinizde olduğuna göre, favori web tarayıcınızda aşağıdaki adrese gitmek isteyeceksiniz. Bağlanamıyorsanız, Raspberry Pi'nizi yeniden başlatmayı ve birkaç dakika beklemeyi deneyin.

"<IPADRESI>" kısmını Raspberry Pi'nizin IP'siyle değiştirdiğinizden emin olun.

https://<IPADRESI>:8006

31. Proxmox web arayüzü artık web tarayıcınızda açık olduğuna göre, hesabınıza giriş yapmanız gerekiyor.

Kullanıcı adı olarak "root" yazarak başlayın ve ardından bu kullanıcı için daha önce belirlediğiniz şifreyi kullanın (1.).

Bilgilerinizi doldurduktan sonra, "Login" düğmesine tıklayın (2.).

32. Artık Proxmox web arayüzüne erişiminiz olmalıdır.

Bu arayüz üzerinden yeni VM'ler kurmaya ve Proxmox VE'nin kendisini yapılandırmaya başlayabilirsiniz.

Sonuç

Umarız bu eğitimin bu aşamasında, artık Raspberry Pi'nize Proxmox VE kurulu olur.

Bu aracı, Pi'nizde sanal makineler kurmak ve yönetmek için kullanabilirsiniz. Özellikle birden fazla sanal makineyle uğraşanlar için güçlü bir hipervizördür.
