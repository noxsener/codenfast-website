Raspberry Pi Minecraft Sunucusu

Bu yazı, PiMyLifeUp - Raspberry Pi Minecraft Server kaynağından Türkçe'ye çevrilerek hazırlanmıştır.

Bir Raspberry Pi Minecraft sunucusu, arkadaşlarınızla veya sadece uğraşmak için kendi özel sunucunuza sahip olmanın uygun maliyetli bir yoludur.

Benimki oldukça uzun süredir çalışıyor ve çok fazla sorunla karşılaşmadım. Bu sunucunun çok fazla insanı tutamayacağını bilmek çok önemli.

Deneyimlerimden, beş kişinin üzerindeki her şey ve sunucu biraz garip davranmaya başlayacaktır. Optimal insan miktarının sadece iki ila üç olduğunu buldum, ancak bu sunucuyu ayarlayarak iyileştirilebilir.

Ayrıca varsayılan kurulum benim için işe yaramadığından Minecraft'ın spigot sürümünü kullanacağız. Çok sık çöktüğünü, gecikmeli olduğunu ve çok kararsız olduğunu buldum. Resmi Java sürümü zamanla iyileşebilir.

Bedrock sunucusu arıyorsanız, Minecraft Bedrock sunucusu eğitimimize göz atmayı unutmayın. Onu doğru şekilde kurmanın tüm adımlarında size yol gösterecektir.

Bu projede, Raspberry Pi OS'de zaten kurulu olması gereken Java kullanacağız. Sunucuyu Raspberry Pi 2, 3, 4 veya 5 için optimize etmek üzere birkaç değişiklik yapacağız. Ayrıca ona web üzerinden erişebilmeniz için ayarlayacağız ve Pi herhangi bir nedenden dolayı çevrimdışı olursa yeniden başlamasını sağlayacağız.

Raspberry Pi Minecraft Sunucusunu Kurma

Öncelikle, Raspberry Pi'ye bir işletim sistemi kurmalıyız. Bunu henüz yapmadıysanız, Raspberry Pi OS kurma hakkındaki harika rehberimize göz atın. Yapmanız gereken tüm adımlarda size yol gösterecektir.

Bu eğitimde, tamamen terminalde çalışacağız. GUI'yi yüklemeyerek kaynaklardan tasarruf edebilmemiz için muhtemelen doğrudan terminale önyükleme yapmamız en iyisi.

1. İlk olarak, aşağıdaki komutları girerek işletim sistemi paketlerini en son sürüme güncelleyin.

sudo apt update
sudo apt upgrade

2. Şimdi, yapılandırma aracında birkaç değişiklik yapmamız gerekecek. Aşağıdaki satırı girerek aracı açalım.

sudo raspi-config

raspi-config aracı hakkında daha fazla bilgiye ihtiyacınız varsa, lütfen rehberimize göz atın.

3. Ayrıca, masaüstüne önyükleme yapmak istemeniz pek olası değil, bu yüzden önyükleme seçeneğinin CLI'ye (Command Line Interface) ayarlandığından emin olun. Bu değişiklik, sunucuya mümkün olduğunca fazla işlem gücü vermeye yardımcı olacaktır.

Önyükleme seçeneğini değiştirmek için, 1 System Options'ı seçin ve Boot / Auto Login'i seçin.

Console veya Console Autologin'i seçin.

4. Son olarak, henüz etkinleştirmediyseniz gerektiğinde Pi'ye uzaktan erişebilmemiz için SSH'yi etkinleştirin.

SSH'yi etkinleştirmek için, Interface Options'a gidin. Ardından, I1 SSH'i seçin. Son olarak, SSH sunucusunu etkinleştirmek için 'i yanıtlayın.

5. Şimdi ana ekranda 'e gidin ve yeniden başlatma sorusuna 'i yanıtlayın.

6. Şimdi sunucumuza bağlanmayı denediğimizde Pi'mizin IP adresini isteyeceğiz. Raspberry Pi'nin IP adresini almak için, hostname komutunu girin.

sudo hostname -I

IP'nin değişmemesini sağlamak için, Raspberry Pi'nizde ve router'ınızda statik bir IP adresi kurmalısınız.

7. Ardından, Git ve jq'nun kurulu olduğundan emin olmamız gerekiyor. Aksi takdirde, sunucuyu inşa edemeyeceğiz.

Git yazılımını ve jq'yu kurmak için aşağıdaki komutu girin. jq, terminal içinde JSON verisini kolayca yorumlamamızı sağlar.

sudo apt install git jq

8. Varsayılan olarak, Java (17) Raspberry Pi OS'de (Bookworm) zaten mevcut olmalıdır. Ancak, Minecraft sunucusunun en son sürümünü kullanmak isterseniz, mevcut olandan daha yeni bir sürüm kullanmanız gerekecek.

Minecraft 1.20.6+ (Java 21 veya 22) ile uyumlu bir Java sürümü kurmak için, lütfen Java kurma rehberimizi takip edin.

9. Şimdi, Spigot'un sağladığı bir builder aracını kullanarak oluşturacağımız Minecraft sunucu dosyasına ihtiyacımız olacak.

Araçları almak için, aşağıdaki komutları girin.

mkdir ~/minecraft
cd ~/minecraft
wget https://hub.spigotmc.org/jenkins/job/BuildTools/lastSuccessfulBuild/artifact/target/BuildTools.jar

10. Şimdi build tools dosyasını çalıştırmak isteyeceğiz, böylece Spigot sunucumuzu oluşturacaktır. Bitmesi yaklaşık 15 dakika sürecektir.

Farklı bir sürüm almak için komutun sonundaki --rev latesti değiştirin. Komuttaki latest'i indirmek istediğiniz sürüm numarasıyla değiştirmeyi unutmayın. Örneğin, --rev 1.20.6, 1.20.6 sürümünü indirecektir.

java -Xmx1024M -jar BuildTools.jar --final-name server.jar --rev latest

Önemli: Bir Raspberry Pi B+, B veya Raspberry Pi 2'den önceki herhangi bir varyasyona sahipseniz, build tools muhtemelen başarısız olacaktır. Bunun yerine spigot.jar'ı daha güçlü bir bilgisayarda oluşturmanız gerekecek.

11. Spigot sunucusunun başarıyla indirilip kaydedildiğinden emin olmak için, sadece ls yazın. spigot-1.20.6.jarı görmelisiniz. İndirdiğiniz sürüme bağlı olarak dosya adı farklı olabilir.

ls

Tüm sunucu dosyalarının burada oluşturulmasını istediğimizden ~/minecraft klasöründe kaldığınızdan emin olun. Sunucuyu farklı bir klasörde başlatırsanız, dosyaları orada oluşturacaktır.

12. Artık sunucuyu başlatmaya hazırız. Bunu yapmak için, aşağıdaki komutu girin. Kullandığınız sürüme bağlı olarak sürüm numarasını değiştirmeniz gerekebilir, örn. spigot-1.20.6.jar.

Raspberry Pi 1

java -Xms256M -Xmx496M -jar ~/minecraft/server.jar nogui

Raspberry Pi 2, 3, 4 veya 5

java -Xms512M -Xmx1008M -jar ~/minecraft/server.jar nogui

Raspberry Pi 4 veya 5'in 2GB ve 4GB varyantlarıyla, Xmx değerini daha da artırabilirsiniz.

Eula'yı kabul etmemiz gerekeceğinden sunucu hemen duracaktır. Bunu, aşağıdaki komutu yazarak Eula'yı açıp yapabilirsiniz.

nano eula.txt

13. Burada, "false"u "TRUE" olarak değiştirin. Bittiğinde, CTRL + X, ardından Y tuşuna basarak kaydedip çıkın.

14. Şimdi sunucuyu tekrar başlatın. Bir harita oluşturması biraz zaman alacaktır, bu yüzden ona üç ila beş dakika verin. Bir daha yeniden başlatırsanız, harita zaten oluşturulduğundan yüklenmesi sadece otuz saniye sürecektir.

15. Sunucu çalışıyor ve yerel ağ üzerinden erişilebilir olmalıdır.

16. Şimdi kullanıcınızı mod'lamak isteyebilirsiniz, böylece giriş yaptığınızda tüm sunucu komutlarını kullanabilirsiniz. Başlangıçta otomatik önyüklemesi varsa, sunucu backend'ine erişmek biraz daha zor olur.

Kullanıcınızı mod'lamak için, sunucu başladığında sadece aşağıdaki komutu çalıştırın (username'i kendi kullanıcı adınızla değiştirin).

op username

17. Raspberry Pi'deki Minecraft sunucusu artık iyi çalışıyor olacak, ancak sunucuyu daha da iyi çalıştırmak için bazı optimizasyonlar yapmak isteyebilirsiniz.

Minecraft Sunucusuna Bağlanma

Yerel bir ağdaysanız, Raspberry Pi'de çalışan Minecraft sunucusuna bağlanmak oldukça kolay olmalıdır. Test etmek için, aşağıdaki adımları takip edin.

1. Pi ile aynı yerel ağda bulunan bir bilgisayarda Minecraft Java istemcisini yükleyin. İstemcinin sürümünün sunucunun sürümüyle eşleştiğinden emin olun.

2. Multiplayer'a gidin ve sunucunuz yerel listede görünebilir. Görünmezse, sadece direct connect'e gidin ve daha önce hostname komutunu kullanarak Pi'de aldığımız IP adresini girin.

hostname -I

3. Minecraft sunucusuna internet üzerinden erişime izin vermek isterseniz, port yönlendirmesi kurmanız gerekecek.

Bunu nasıl yapacağınızı öğrenmek istediğinizi varsayarak, Raspberry Pi port yönlendirmesi kurma rehberime gidin. 25565 portunu (sunucu özelliklerinde değiştirmediğiniz sürece) Pi'nizin IP'sine port yönlendirmeniz gerekecek.

Sunucuyu Yapılandırma

İşte sunucuyu yapılandırma ve çalışır hale getirme için birkaç ipucu.

Minecraft Sunucusunu Optimize Etme

Raspberry Pi'deki Minecraft sunucumuzdan en iyi verimi almak için, performansı optimize etmeye yardımcı olacak bir eklenti kurabilirsiniz.

Performansa yardımcı olabilecek veya sunucunun işlevselliğini genişletebilecek birçok eklenti vardır. Bunları Pi'ye indirmek için sadece wget komutunu kullanın. Aşağıda bir örnek var.

cd ~/minecraft/plugins
wget -O example.jar <example_plugin_url>

Minecraft Özelliklerini Düzenleme

Muhtemelen sunucu özelliklerini nasıl düzenleyeceğinizi bilmek isteyeceksiniz. Bu düzenleme yeteneği, sunucuyu optimize etmek ve sunucunun nasıl olmasını istediğinize göre özelleştirmek için çok önemlidir.

Sunucu ayarlarının her biri hakkında daha fazla bilgi isterseniz, tüm sunucu özellikleri hakkında burada iyi bir sayfa bulabilirsiniz.

Sunucu özelliklerine girmek için, aşağıdaki satırı girin.

sudo nano ~/minecraft/server.properties

Şimdi, sunucunun performansını optimize etmeye yardımcı olması için birkaç ayarı değiştirmek isteyeceğiz.

Bunları ve diğer ayarları istediğiniz herhangi bir şekilde değiştirebilirsiniz, ancak Pi'nin çok fazla işlemi kaldıramayacağını unutmayın.

view-distance=04
max-player=5

Önyüklemede Başlatma

Sunucunun önyüklemede başlaması için, birkaç ekstra adım atmamız gerekecek.

1. Minecraft sunucusu için bir servis oluşturmamız gerekecek, bu yüzden aşağıdaki komutu girerek servis dosyasını yazmaya başlayalım.

sudo nano /lib/systemd/system/minecraftserver.service

2. Bu dosyaya, aşağıdaki metni girmeniz gerekecek.

Bu dosya servisi tanımlar, böylece servis yöneticisi neyi ve nasıl çalıştıracağını bilir. Her yükselttiğinizde spigot sürüm numarasını güncellemeyi unutmayın.

"<KULLANICI>" kısmını sunucuyu çalıştırmak için kullanmayı planladığınız kullanıcı adıyla güncelleyin. Terminale whoami komutunu girerek kullanıcınızın kullanıcı adını görebilirsiniz.

[Unit]
Description=Minecraft Spigot Server

[Service]
User=<KULLANICI>
Group=<KULLANICI>
Restart=on-abort
WorkingDirectory=/home/<KULLANICI>/minecraft/
ExecStart=/usr/bin/java -Xms512M -Xmx1008M -jar /home/<KULLANICI>/minecraft/server.jar nogui

[Install]
WantedBy=multi-user.target

Bittiğinde, CTRL + X, ardından Y, sonra ENTER tuşuna basarak dosyayı kaydedin.

3. Şimdi, servisi etkinleştirmemiz gerekecek. Aşağıdaki komutu çalıştırarak servisi etkinleştirebilirsiniz.

sudo systemctl enable minecraftserver.service

4. Artık sadece aşağıdaki komutu kullanarak Minecraft sunucusunu başlatabilmeniz gerekiyor.

sudo systemctl start minecraftserver.service

5. Benzer bir komut kullanarak, servisin durumunu kontrol edebilirsiniz. Durumu kontrol etmek hata ayıklama için harikadır.

sudo systemctl status minecraftserver.service

5. Aşağıdaki komutu kullanarak sunucuyu durdurabilirsiniz.

sudo systemctl stop minecraftserver.service

Sunucunuz artık önyüklemede başlamalıdır. Raspberry Pi'yi yeniden başlatarak bunu test edebilirsiniz. Başlaması birkaç dakika sürecektir.

sudo reboot

Sunucuya komut satırında erişim kazanmak isterseniz, sunucuyu kapatmanız ve onu normal komutu kullanarak yüklemeniz gerekecek.

Raspberry Pi'de Minecraft Sunucunuzu Güncelleme

Bu bölümde, Raspberry Pi'nizdeki Minecraft sunucusunu en son sürüme nasıl güncelleyeceğinizi göstereceğiz.

1. Minecraft sunucusunu güncellemeye başlayabilmemiz için, sunucunun saklandığı dizine geçmemiz gerekecek.

Eğitimimizi takip ettiyseniz, bu, aşağıdaki komutu çalıştırarak doğru yere geçebilmeniz gerektiği anlamına gelir.

cd ~/minecraft/

2. Doğru yerde olduğumuza göre şimdi yapmak isteyeceğimiz ilk şey, Spigot build tools'un en son sürümüne sahip olduğumuzdan emin olmaktır.

En son sürümü indirmek için terminalde aşağıdakini kullanarak wget komutunu kullanabiliriz.

wget https://hub.spigotmc.org/jenkins/job/BuildTools/lastSuccessfulBuild/artifact/target/BuildTools.jar

3. Build tools güncellendiğine göre, şimdi aşağıdaki komutu kullanarak Minecraft sunucusunun en son sürümü için sürüm numarasını alabiliriz.

Raspberry Pi'nizde kullanmak istediğiniz belirli bir Minecraft sunucusu sürümü varsa komutu burada onunla değiştirin. Aksi takdirde, peşinde olduğumuz sürüm numarasını almak için biraz curl ve jq büyüsü kullanabiliriz.

MINECRAFT_VERSION=$(curl -sS https://launchermeta.mojang.com/mc/game/version_manifest.json | jq -r '{latest: .latest.release} | .[]')

4. Sürüm numaranızı ortam değişkenine kaydettikten sonra devam edebiliriz.

Raspberry Pi'mizdeki Minecraft sunucusunu güncelleyebilmemiz için, mevcut olanın çalışmasını durdurmamız gerekecek. Aşağıdaki komutu çalıştırarak çalışan sunucuyu durdurabilirsiniz.

sudo systemctl stop minecraftserver

5. Şimdi Minecraft sunucunuzu en son sürüme indirmek ve güncellemek için Spigot build tools'u kullanın.

Lütfen bu sürecin tamamlanmasının birkaç dakika sürebileceğini unutmayın.

java -Xmx1024M -jar BuildTools.jar --final-name server.jar --rev $MINECRAFT_VERSION

6. Güncelleme süreci tamamlandıktan sonra, aşağıdaki komutu kullanarak sunucuyu başlatabilirsiniz.

sudo systemctl start minecraftserver

Sonuç

Umarım bu eğitim, kararlı bir sürüm Raspberry Pi Minecraft sunucusu kurmanıza yardımcı olmuştur. Bu eğitimi beğendiyseniz, başka birçok Raspberry Pi Projemize göz atmayı unutmayın.

Ayrıca, daha iyi optimizasyon ayarlarınız, eklentileriniz veya fikirleriniz varsa aşağıya bir yorum bırakmaktan çekinmeyin. Sorun yaşıyorsanız, aşağıda bize bildirin.
