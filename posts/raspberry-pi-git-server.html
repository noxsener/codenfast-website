Kendi Raspberry Pi Git Sunucunuzu Kurun

Bu yazı, PiMyLifeUp - Build your own Raspberry Pi Git Server kaynağından Türkçe'ye çevrilerek hazırlanmıştır.

Bu eğitimde, bir sonraki kod projenizi barındırmak için mükemmel olan basit ama havalı bir Raspberry Pi Git sunucusu yapıyoruz.

Bir programcıysanız, muhtemelen Git'i daha önce duymuşsunuzdur. Duymayanlar için, Git yazılım geliştirme için son derece popüler bir versiyon kontrol yazılımıdır.

Dışarıda birçok hosted Git çözümü var, ancak bir nedenden veya diğerinden dolayı kendi özel Git sunucunuzu istiyor olabilirsiniz. Kodunuz üzerinde tam kontrole sahip olmak ve onu mümkün olduğunca özel tutabilmek gibi.

Kendi Git Sunucunuzu nasıl çalıştıracağınızı öğrenmenin iyi bir faydası, çoğu Git komutu hakkında bir anlayış kazanmanızdır. Bu komutları bilmek, özellikle bir GIT grafik arayüzü kullanmayan işlerde son derece kullanışlıdır.

Raspberry Pi Git Sunucusunu Kurma

Raspberry pi Git sunucusunu kurma süreci oldukça basittir. Git'e ve komutlarına aşina değilseniz, onları öğrenmek için zaman ayırmanızı şiddetle öneririm. Sayfanın devamında birkaç temel konuya değineceğim ve Git kullanımı hakkında daha fazla bilgi edinebileceğiniz birkaç iyi yer de belirteceğim.

1. Her zamanki gibi önce Pi'nin güncel olduğundan emin olalım. Aşağıdaki komutları çalıştırın.

sudo apt update
sudo apt upgrade

İlk olarak, Git'in kurulu olduğundan emin olun. Zaten kurulu olmalıdır.

sudo apt install git-core

2. SSH'nizin etkinleştirildiğinden emin olmanız gerekecek. Bunu henüz yapmadıysanız, SSH eğitimimizde bunu nasıl yapacağınızı bulabilirsiniz.

3. Şimdi bunu bir USB sürücüde saklamak isteyebilirsiniz. Bunu yapmak istiyorsanız, USB sürücüyü bağlamanız (mount) gerekecek. Raspberry Pi'de bir USB sürücüyü bağlama rehberimizi son derece kullanışlı bulacaksınız.

Git sunucusunu çalışır hale getirmek için yapmanız gereken şeylerin hepsi bu süreçtir. Gerçekten oldukça kolay, bir sonraki bölümde ilk deponuzu oluşturmaya ve ona güncellemeler göndermeye bakacağız.

İlk Deponuzu Kurma

Şimdi koda/veriye göndermeye başlayabilmemiz için kendi ilk deponuzu yapalım. Muhtemelen öğrenmek isteyeceğiniz daha karmaşık komutlar var, ancak bu temeller sizi başlatmak için mükemmel olacak.

1. İlk olarak, yeni deponuzun saklanacağı yer için bir dizin oluşturmamız gerekiyor. -p etiketi, yolumuzda henüz mevcut olmayan tüm dizinleri oluşturacaktır.

mkdir -p /home/pi/git/myFirstRepository

2. Şimdi cd komutunu kullanarak dizine geçelim.

cd /home/pi/git/myFirstRepository

3. Şimdi bare komutunu kullanarak Git deposunu başlatalım.

git init --bare

4. Yeni bir depo oluşturmanız gerektiğinde bu adımları tekrarlamanız gerekecek. Bunların hepsi yapıldığına göre, ilk commit'imizi yapmaya hazırız.

5. Windows veya Mac bilgisayarda, deponuza kod göndermeye başlayabilmek için Git'i indirmeniz gerekecek. git-scm indirip kullanmanızı öneririm.

6. Kurduktan sonra, bir klasörün içinde sağ tıkladığınızda bazı ek seçenekleriniz olmalı.

7. Commit etmek istediğiniz klasörde, sağ tıklayın ve ardından Git bash'e gidin. Bir komut istemine benzeyen bir pencere açmalı.

8. Bu zaten bir Git dizini değilse, koda Pi'mize göndermeden önce onu başlatmanız gerekecek. Bunu yapmak için aşağıdaki komutu girin:

git init

9. Şimdi aşağıdaki satırı ekleyerek uzak Git dizinimizi eklememiz gerekiyor.

git remote add myFirstRepository pi@192.168.1.108:/home/pi/git/myFirstRepository

10. Şimdi kolayca deponuza veri gönderebiliriz. Bunu yapmak için aşağıdaki komutları girin.

git add .
git commit -m "Our first commit"
git push myFirstRepository master

11. Bir başarı mesajı gelmesi gerekiyor. Bu mesaj, kodumuzun Git sunucumuza gönderildiği anlamına gelir.

12. Her şeyin doğru çalıştığından emin olmak için, az önce kurduğumuz depoyu yeni bir klasöre klonlayabilirsiniz. Önce, farklı bir klasörde Git bash'i açın ve ardından aşağıdaki komutları çalıştırın:

git clone pi@192.168.1.108:/home/pi/git/myFirstRepository/

13. Görebileceğiniz gibi, Raspberry Pi Git sunucusu artık kodumuzu doğru şekilde saklıyor. Şimdi, bu Git'in çok temelleri ve öğrenilecek çok daha fazla şey var.

Şimdi Git ve kullanabileceğiniz komutlar hakkında öğrenilecek çok daha fazla şey var. Git hakkında ve nasıl çalıştığı hakkında daha fazla bilgi edinmede son derece yardımcı olan birkaç web sitesiyle karşılaştım. Programlamaya girmeyi düşünüyorsanız, kod versiyon kontrol sistemleri hakkında bilgi edinmeniz önemlidir.

Git hakkında daha fazla bilgi edinmek isterseniz, codecademy'nin göz atabileceğiniz muhteşem eğitimleri var. Ayrıca, Git-scm kullanabileceğiniz birçok farklı komut hakkında bol miktarda harika belgeye sahiptir.

Özel Git Sunucusuna Uzaktan Erişme

Şimdi Git depolarınıza yerel ağınız dışından erişmek isteyebilirsiniz. Bunu yapmak için, router'ınızda port yönlendirmesi kurmanız gerekecek.

Bir port üzerinden iletişime izin vermenin bazı güvenlik riskleri vardır ancak sunucunuza erişim kazanmanın en kolay yoludur.

Dış erişime izin verecekseniz, pi kullanıcısının parolasını çok daha güçlü bir şeyle güncellemeniz önemlidir.

Dış erişim kurmak isterseniz, Raspberry Pi ile port yönlendirme rehberimize göz atın. Yerel ağınız dışından erişim kazanmak için SSH portunu (22) port yönlendirmeniz gerekecek.

22 dışında harici bir port kullanıyorsanız, bunu ya ~/.shh/ssh_config içinde belirtmeniz ya da aşağıdaki gibi bunun yerine bir URL tarzı adres kullanmanız gerekecek.

ssh://pi@XXX.XXX.XXX.XXX:23/home/pi/git/myFirstRepository.git/

Burada X, harici IP'nizi ve 23 harici portu temsil eder.

Umarım artık tamamen çalışan bir Raspberry Pi Git sunucunuz vardır. Herhangi bir sorunla karşılaşırsanız, bir şey kaçırdıysam veya başka bir şey varsa, aşağıya bir yorum bırakmayı unutmayın.
