Raspberry Pi'de WordPress Nasıl Kurulur

Bu yazı, PiMyLifeUp - How to Set Up WordPress on the Raspberry Pi kaynağından Türkçe'ye çevrilerek hazırlanmıştır.

Bu eğitimde, popüler WordPress CMS'ini Raspberry Pi'nizde nasıl ayarlayacağınızı öğreneceksiniz.

Bilmeyenler için, WordPress 60 milyondan fazla web sitesi tarafından kullanılan bir içerik yönetim sistemidir (CMS). Bloggerlar arasında çok popülerdir ancak büyük web siteleri tarafından da kullanılır.

Şu anda XAMPP gibi bir şey kullanmaktan daha hızlı olduğu için geliştirme sunucusu olarak görev yapmak üzere Raspberry Pi'mde WordPress çalıştırıyorum.

WordPress'i Raspberry Pi'de ayarlamak çok karmaşık değildir. Apache, PHP ve MYSQL sunucusunu ayarladıktan sonra, işler sorunsuz ilerler.

Bu eğitimde çok ileri gitmeden önce, MYSQL root parolanızın hazır olduğundan emin olun. WordPress için bir veritabanı ayarlama adımlarından geçeceğiz ve size veritabanıyla etkileşim kurmak için tamamen MYSQL komut satırını kullanarak bir SQL kullanıcısı nasıl ayarlanır göstereceğiz.

İlgileniyorsanız, artık WordPress'i Raspberry Pi'de ayarlama zamanı.

Raspberry Pi'de WordPress Ayarlama

Bu eğitime başlamadan önce Apache ve PHP'yi ayarladığınızdan emin olun. Ayrıca çalışan ve erişilebilir bir MYSQL sunucusuna sahip olmanız gerekecek. Daha önce belirttiğim gibi, MYSQL root parolanızın hazır olması gerekecek.

WordPress'i İndirme ve Çıkarma

1. Başlamak için, WordPress'i Raspberry Pi'mizdeki "/var/www/html" dizinine indirip çıkarmamız gerekiyor. Çıkardıktan sonra wordpress kurulum dizinini, zip dosyasını ve hala varsa orijinal örnek Apache index.htmlini kaldıracağız.

Bunu başarmak için birkaç komut çalıştıracağız, aşağıdaki her satırı terminale yazmanız yeterli.

cd /var/www/html
sudo wget https://wordpress.org/latest.tar.gz
sudo tar xzf latest.tar.gz
sudo mv wordpress/* ./
sudo rm -rf wordpress latest.tar.gz
sudo rm -f index.html

2. Şimdi bazı izin değişiklikleri yapmamız gerekiyor. İlk olarak, gerekirse dosyalarda değişiklik yapabilmek için kullanıcımızı www-data grubuna ekliyoruz.

"/var/www/html" klasörünün sahipliğini "www-data" kullanıcısı ve grubuyla almamız gerekecek. Bunu yapmak, PHP'nin herhangi bir izin hatasıyla karşılaşmadan WordPress'i işlemesine olanak tanıyacaktır.

Son olarak, dizinleri ve dosyaları doğru okuma, yazma, çalıştırma izinlerine sahip olacak şekilde ayarlamak istiyoruz. Dizinler için 755, dosyalar için 644 ayarlayacağız. Bu komutları çalıştırmadan önce /var/www/html dizini içinde olduğunuzdan emin olun.

sudo usermod -a -G www-data $USER
sudo chown -R -f www-data:www-data /var/www/html
find . -type d -exec chmod 755 {} \;
find . -type f -exec chmod 644 {} \;

Apache'yi Hazırlama

3. WordPress için Apache'yi hazırlamak için atmamız gereken birkaç adım var. Bu adımlar, WordPress'in özel permalink ayarlarını kullanmak istiyorsanız önemlidir.

Önce Apache web sunucusu için rewrite modülünü etkinleştirmeliyiz. Bunu a2enmod komutunu kullanarak yapabilirsiniz.

sudo a2enmod rewrite

Yukarıdaki komutu çalıştırdıktan sonra, yeni modülümüzün doğru şekilde yüklenmesi için Apache'yi yeniden başlatın.

sudo systemctl restart apache2

4. Ardından, ana Apache yapılandırma dosyası içinde bir ayar değiştirmemiz gerekecek. Öncelikle, aşağıdaki komutu çalıştırarak yapılandırma dosyasını açın.

sudo nano /etc/apache2/apache2.conf

5. Dosyanın içinde, aşağıdaki metinle eşleşen kod parçasını bulmanız gerekecek.

CTRL + W kullanmak, dosyada arama yapmanızı ve belirli bir metni bulmayı hızlandırmanızı sağlayacaktır. Örneğin, AllowOverride aramak sizi bu ayarları bulacağınız alana götürecektir.

<Directory /var/www/>
    Options Indexes FollowSymLinks
    AllowOverride None
    Require all granted
</Directory>

Bu blok içinde, AllowOverride ayarını Nonedan Alle değiştirin. Bunu yaparak Apache'nin WordPress'in .htaccess dosyasını okumasına izin veriyoruz. Bu son derece önemlidir çünkü .htaccess dosyası, WordPress'in permalink'ler için kurallarını kaydedeceği yerdir.

<Directory /var/www/>
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>

Bittiğinde, CTRL + X, ardından Y, sonra Enter tuşuna basarak kaydedip çıkın.

6. Yukarıdaki adımları tamamladıktan sonra, değişikliklerin etkili olması için Apache'yi yeniden başlatmanız gerekecek. Bunu aşağıdaki komutu çalıştırarak yapabilirsiniz.

sudo systemctl restart apache2

Her şey doğru çalıştıysa, Apache herhangi bir sorun yaşamadan yeniden başlayacaktır. Aşağıdaki komutu çalıştırarak Apache'nin durumunu kontrol edebilirsiniz.

sudo systemctl status apache2

WordPress Veritabanını Oluşturma

7. WordPress artık Raspberry Pi'mize indirilip çıkarıldığına göre, WordPress'in bilgilerini saklaması için MYSQL içinde bir veritabanı da ayarlamamız gerekecek.

Önce giriş yapmak için MySQL komutunu kullanmamız gerekiyor. Parola için "–p" bayrağını ve kullanıcı adı için "–u"yu kullanın. Parolanızın "-p" etiketinin hemen yanına boşluk olmadan yazıldığından emin olun.

Not: parola kısmını MySQL'i kurarken root kullanıcısı için ayarladığınız parolayla değiştirin.

sudo mysql -u root -p

8. MYSQL sunucusuna giriş yaptığımıza göre, bu basit satırı kullanarak WordPress için bir veritabanı oluşturmak üzere bir komut verebiliriz:

CREATE DATABASE wordpress;

9. Şimdi bu veritabanı için ayrı bir kullanıcı oluşturacağız, bu güvenlik açısından çok daha güvenlidir.

Hala MYSQL içindeyken aşağıdaki komutu verin:

CREATE USER 'new_user'@'localhost' IDENTIFIED BY 'new_password';

Not: new_user ve new_password kısımlarını kendi seçtiğiniz detaylarla değiştirdiğinizden emin olun, WordPress'i ayarlarken ikisini de bilmeniz gerekeceğinden ne seçtiğinizi hatırlayın.

10. Yeni bir kullanıcımız olduğuna göre, ona yeni veritabanımızı yönetme izinleri vermemiz gerekecek.

Bunu aşağıdaki komutla yapabiliriz, new_user kısmını bir önceki adımda girdiğiniz şeyle değiştirdiğinizden emin olun.

GRANT ALL ON wordpress.* TO 'new_user'@'localhost';

11. Artık veritabanımızı ve onunla etkileşim kurmak istediğimiz kullanıcımızı oluşturduk. MYSQL komut arayüzünden çıkmamız gerekiyor.

Bunu CTRL + D tuşlarına basarak yapabiliriz.

WordPress İlk Kurulum Sihirbazı

12. Bunların hepsi yapıldığına göre, artık sonunda WordPress'i ayarlamayı bitirebiliriz, bu süreci bir web tarayıcısında Raspberry Pi'nizin IP adresine giderek başlatabiliriz.

Sizden bir dil seçmenizi isteyen aşağıdaki ekranla karşılaşacaksınız.

13. Bir sonraki sayfa, WordPress'i kurmak için hazır bulundurmanız gereken detayları açıklayacaktır. Önemli ekrana gitmek için sadece "lets go"ya basabilirsiniz.

14. Şimdi WordPress'in kurduğumuz MySQL veritabanına bağlanabilmesi için çeşitli detayları girmeniz gerekecek.

  • Database Name (Veritabanı Adı) – Bu, WordPress'in bağlanacağı veritabanıdır. Bu eğitimde daha önce wordpress adlı bir veritabanı oluşturmuştuk.
  • Username (Kullanıcı Adı) – Bu, 4. adımda oluşturduğumuz kullanıcıdır, yukarıdaki veritabanına bağlanması gerektiğinden bu detayı doğru aldığınızdan emin olun.
  • Password (Parola) – Bu, 4. adımda MYSQL kullanıcısını oluştururken belirlediğimiz paroladır, yine veritabanına bağlanmak için gerekli olduğundan bunu doğru girdiğinizden emin olun.
  • Database Host (Veritabanı Host'u) – Bunu varsayılan ayarında bırakın, yalnızca yerel olarak bağlanmamız gerekiyor.
  • Table Prefix (Tablo Öneki) – Bunu da varsayılan ayarında bırakın, bunu değiştirmeye gerçek bir gerek yok.

15. Tüm doğru detayları girdiğinizi varsayarsak, artık yazılımı başarıyla kurmak için "Submit"e basabilir ve kurulumu tamamlamak için istemlerin geri kalanını takip edebilirsiniz.

Sonuç

Bir WordPress teması kurmak veya eklentiler ayarlamak gibi WordPress hakkında öğrenilecek daha çok şey var. Bir Raspberry Pi kullanmak, pahalı bir web sunucusuna yatırım yapmadan tüm temelleri öğrenmenin harika bir yoludur.

Artık WordPress'i Raspberry Pi'de ayarlamış ve erişilebilir hale getirmiş olmalısınız. Herhangi bir sorunla karşılaşırsanız, bir yorum bırakarak bize bildirmekten çekinmeyin.
